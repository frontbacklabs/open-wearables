**Settings → Providers** controls which OAuth providers your end users can connect.

## Enabling a provider

Each provider row shows its current state (**Enabled** or **Disabled**) and a toggle. Flip the toggles you want to change, then confirm with **Save Changes** in the bar that appears at the bottom of the page. Nothing is saved until you click it.

A provider still needs its OAuth client credentials configured in the backend environment before users can connect it. See [Supported Providers](/providers/supported) for the per-provider setup guides.

## Live sync mode

The portal does not expose the live-sync mode control. Providers that support both delivery methods keep their mode in backend settings; an instance admin changes it with `PUT /api/v1/oauth/providers/{provider}` and a developer JWT - see [Live Sync Mode](/api-reference/guides/provider-setup#live-sync-mode). Webhook mode also requires a publicly reachable backend and, for some providers, a registered webhook subscription.
